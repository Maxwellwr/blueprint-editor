# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Status

This repository (`blueprint-editor`) is currently an empty scaffold: it has no commits, no source files, and no build/lint/test tooling configured yet. Design and process are documented (see below); there is no code to document architecturally yet.

When real project files are added (source code, package manifests, config, a README, etc.), this file should be regenerated by running `/init` again so it reflects the actual commands (build/lint/test) and architecture of the codebase at that point.

Language of a project is Russian. All artifacts must be in russian language. This also covers the conversation itself — Claude Code's chat replies to the user in this repository must be in Russian, not just committed files.
