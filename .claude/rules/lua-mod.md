# Код мода

Короткая выжимка того, что ревью проверяет в первую очередь. Источник и обоснование — `docs/sdlc.md` («Архитектурные принципы», «Версия Factorio и проверка API-фактов») и ADR-0001; при сомнении читать их, а не эту выжимку.

- **Документация API — только запиненная.** `https://lua-api.factorio.com/2.0.77/...`, никогда `/latest/` (он отслеживает experimental и уже приводил к крашу в Phase 1). Новый API-факт, на который опирается код, — в раздел «Найденные API-факты» `phase-N-implementation.md` (исполнитель сообщает его в отчёте).
- **`storage` — только через `scripts/state.lua`.** Мутации сессии — только через `scripts/canvas.lua`; `input.lua` и GUI не трогают `storage` и `rendering` напрямую.
- **Миграции.** Любое изменение схемы `storage` / `Session` / `EntityRecord` — шаг в `scripts/migrations.lua` с версией из `info.json`. Поля только добавляются как nil-safe; удаление или смена смысла поля — решение владельца.
- **Preserve-unknown-fields и `internal_id`.** Импортированная сущность не пересобирается по списку полей; провода и ссылки — по `internal_id`, `entity_number` появляется только на экспорте.
- **Без хардкода имён прототипов** в общей логике (исключение — ad-hoc палитра до Phase 5, помечена в коде). Никаких `if entity.type == "…"` в мутациях.
- **Fail-fast.** Неожиданные данные API — `error()` или явное сообщение игроку, а не тихий пропуск. Тихая деградация — только для косметики.
- **Бюджет производительности.** Компонент, создающий render-объекты или большие структуры, несёт константу-порог с комментарием.
- **Чистая логика — TDD.** Новая функция без зависимости от Factorio API пишется через падающий busted-тест (`spec/<модуль>_spec.lua`). Чистые функции экспортируются из модуля, чтобы тест мог их вызвать.
- **Комментарии в коде — по-русски**, как в существующих модулях; ссылки на ADR и план — в формате `ADR-0001 §6`, `phase-N-plan.md «Задача K»`.
- **Lua 5.2.** Без `//`, побитовых операторов, `utf8`, `<const>` (`commands.md`).
